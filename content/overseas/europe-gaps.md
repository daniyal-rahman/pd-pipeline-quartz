## 1. Database Access Limitations

### EudraCT / CTIS Transition
- **Issue:** EudraCT database only contains trials through January 30, 2025
- **Impact:** New trials registered after this date require CTIS access
- **Status:** CTIS requires specific access credentials for full trial details
- **Recommendation:** Direct CTIS search needed for comprehensive 2025-2026 trial inventory

### EMA Clinical Trials Register
- **Limitation:** Real-time trial status not accessible via web search
- **Impact:** Unable to verify current enrollment status for many trials
- **Workaround:** ClinicalTrials.gov provides some European trial information

## 10. Methodological Limitations

### Search Constraints
1. Web search results biased toward recent/popular content
2. Non-English sources not systematically searched (German, French, Dutch, Danish, etc.)
3. Press releases may lag actual company status
4. Clinical trial registries require direct access for full data

### Verification Issues
1. Company website information may be outdated
2. Some small biotechs have minimal public presence
3. Stealth-mode companies by definition not findable
